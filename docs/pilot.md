# Quran AI Academy — نسخه ۶
وب‌اپ نصب‌شدنی (PWA)، فارسی و بدون API. نسخه قبلی با حل تشریحی بانک سؤال، فلش‌کارت تخصصی با مرور زمان‌بندی‌شده و آزمون زمان‌دار با نمره منفی قابل تنظیم تکمیل شده است.
## اجرا
برای استفاده محلی index.html را باز کنید. برای نصب و استفاده آفلاین، همه فایل‌ها را در یک سایت HTTPS مانند GitHub Pages منتشر کنید، سپس در مرورگر موبایل گزینه افزودن به صفحه اصلی یا نصب را انتخاب کنید. پیشرفت در مرورگر ذخیره می‌شود.
## محدودیت
تمام محتوای کتاب‌ها استخراج نشده است؛ سؤال‌ها تألیفی‌اند و جایگزین دفترچه واقعی کنکور نیستند. ضرایب رسمی و لغات الرائد کامل نیستند. استاد مولد AI و APK بومی در این نسخه وجود ندارد. کتاب‌های اصلی داخل بسته نیستند.

## نسخه ۷ — درس آزمایشی
- درس اعراب فعل مضارع، سه سطح، نمودار، ۸ کارت، ۶ سؤال با تحلیل چهار گزینه، آزمون همان بانک با ترتیب تصادفی و نمره منفی، گزارش فعالیت ۱/۷/۳۰ روز و بازخورد محلی.
- منبع: خلاصه نحو PDF ۱–۲؛ نکات در اعراب‌گذاری کنکور PDF ۱؛ فنون ترجمه PDF ۱–۲. مثال و سؤال تألیفی است.
- داده درس در localStorage جدا ذخیره می‌شود؛ خروجی JSON در کارنامه موجود است. انتقال بین دستگاه‌ها خودکار نیست.
- آزمون مرورگر Chromium با صفحه شبیه‌سازی موبایل و تزریق HTML: آموزش، کارت، تحلیل گزینه‌ها، آزمون و گزارش بدون خطای JS اجرا شد. آزمون بارگذاری URL محلی به علت محدودیت محیط ممکن نبود؛ ذخیره پایدار و PWA آفلاین، صدا، نصب واقعی Android و اتصال AI تأیید نشده‌اند.
- نسخه اندروید APK هنوز ساخته نشده است؛ برای انتشار PWA همه فایل‌های پوشه را کنار هم در HTTPS قرار دهید. محتوای کامل کتاب‌ها، ویدئو و پادکست و API هنوز آماده نیستند.
